# Birthday Present

A small interactive Python project created as a birthday-themed program. It combines user interaction, simple games, randomized messages, and ASCII art.

## Project Overview

The program guides the user through a birthday-themed experience. It includes date checking, name validation, and a number-guessing game.

The project is organized into multiple Python modules, each responsible for a different part of the program.

## Features

* User input and validation
* Birthday date checking
* A number-guessing game
* Randomized messages
* ASCII art
* Interactive program flow

## Skills Demonstrated

* Python fundamentals
* Functions and modular code organization
* Conditional statements and loops
* Exception handling
* Random number generation
* Basic input validation

## Technologies

* Python

## How to Run

1. Clone or download the repository.
2. Make sure Python is installed.
3. Run the main Python file, `present.py`.

```bash
python present.py
```

## Project Context

This was an early Python learning project focused on practicing programming fundamentals and building a small interactive application.
